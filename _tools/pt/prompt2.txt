아래 JSON 파일(in2.json)은 한국 스킨케어 브랜드 닥터지(Dr.G) 제품 상세 페이지의 문장 배열입니다. 영어를 기계 번역해서 어색한 한국어(번역투, 어색한 1인칭 '나는', 뜻이 이상한 표현)가 섞여 있습니다.
각 항목을 뜻, 숫자, 제품명, 성분명, 별표(*) 각주 표시를 그대로 유지하면서 자연스러운 한국어 쇼핑몰 문장으로 다듬어 주세요. 후기 문장은 실제 고객이 쓴 듯 자연스러운 구어체('~해요', '~좋아요')로, 이모지는 유지해도 됩니다. 이미 자연스러우면 그대로 두세요. HTML 태그나 따옴표 형태를 바꾸지 말고, 항목 수와 순서를 정확히 유지하세요.
결과는 같은 길이의 JSON 문자열 배열 하나만 최종 답변으로 출력하세요(설명·코드블록 없이 JSON만). 파일을 못 읽었으면 추측하지 말고 못 읽었다고 말하세요.
